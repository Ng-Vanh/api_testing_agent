## Việc chưa được xác nhận

- **T01/Checkpoint M0 còn mở** cho tới khi [CI](../../.github/workflows/tool-m0.yml) chạy cài mới trên Windows/Linux thành công. Đã kiểm trên Linux local, chưa có bằng chứng Windows hoặc clean clone CI.
- Chưa chạy Docker build hoặc kiểm tra giao diện bằng trình duyệt tự động; UI mới được build và kiểm HTTP proxy.
- Readiness fixture hiện dựa trên profile của người vận hành, chưa kiểm DB nghiệp vụ; auth probe là GET tùy cấu hình, `unverified` chặn readiness khi auth bắt buộc.
- JSONL redaction che các key phổ biến và URL query nhạy cảm; secret tự do trong text/binary cần chính sách bổ sung khi xây executor.
- Chưa có testcase execution pipeline, run manager hay worker lấy job: thuộc M1/T10. File plan ví dụ chỉ để kiểm contract.

Người kiểm chứng local: Codex. Nhóm có thể review contract qua schema JSON trước khi chia việc M1.
