## Giới hạn và việc còn mở

- **T01/Checkpoint M0 chưa được đánh dấu đạt** vì chưa có kết quả kiểm tra cài mới trên Windows. Điều này được ghi riêng, không thay bằng bằng chứng Linux.
- M1 CLI chỉ tạo ca GET không có body/parameter bắt buộc. HTTP Executor đã hỗ trợ JSON request độc lập, nhưng sinh dữ liệu và scenario đầy đủ thuộc các mốc sau. Web API quản lý run và UI điều khiển chưa triển khai.
- Một run gồm một probe preflight và một request test; `show` chỉ đọc. Chưa có auto resume/retry; không tuyên bố exactly-once HTTP. LLM, Coverage Tracker và benchmark metric chưa thuộc M1.
- Thử nghiệm MongoDB tạm chỉ cần danh sách sân bay rỗng để kiểm contract; reset/seed Booking vẫn là T09.
- JSON Schema được kiểm trước khi che response; schema không rõ, contract gap, status chưa mô tả hoặc response nén chưa hỗ trợ được báo rõ, không suy diễn thành lỗi nghiệp vụ.
- Nguồn kỹ thuật: [LangGraph Graph API](https://docs.langchain.com/oss/python/langgraph/graph-api), [OpenAPI Schema Validator](https://openapi-schema-validator.readthedocs.io/en/latest/validation.html), [Python HTTP client](https://docs.python.org/3.12/library/http.client.html).
